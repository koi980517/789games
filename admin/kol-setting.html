网红代理设置

备注在「系统参数管理」新增页签，把网红名单从一个文本框改成可添加、可导入、可查看的列表。数据为示例，ID 与账号取自 2026-11-11 QA 测试。

网红代理名单配置

规则：名单内会员用「邀请好友」链接拉来的新会员，上级代理归入 5ji-wanghong；不在名单的会员拉来的新会员归入 5-ji-agent（会员推广专用线）。

  • 只管一层：名单内会员拉来的人如果再邀请，归入 5-ji-agent，除非他也在名单内。
  • 只影响之后的新注册：加入或移出名单，已注册会员的归属都不会变。
  • 网红本人的上级代理不变；网红用代理邀请码拉人不受名单影响。
  • 目标代理固定为 5ji-wanghong，所有网红的下级在同一个代理下，按「邀请人」区分。

优化：文本框改为只读展示，增删改在新页签「网红代理设置」里做，避免手动编辑逗号串时删错或输错 ID。

归属规则

现有后台逻辑，2026-11-11 QA 实测
网红（名单内会员）→ 邀请好友 → 一级：上级代理 5ji-wanghong→ 邀请好友 → 二级：上级代理 5-ji-agent→ 三级及以后：5-ji-agent
  • 一级进 5ji-wanghong名单内会员用邀请好友链接（/invite/会员ID）拉来的新会员，上级代理 = 5ji-wanghong，计入它的直属会员和团队数。
  • 只管一层，不往下传一级会员不在名单内时，他再拉来的人归入 5-ji-agent。实测：M1 在名单 → M4 进 5ji-wanghong；M4 不在名单 → M5 进 5-ji-agent。
  • 只影响之后的新注册归属在注册那一刻决定。加入、停用或移出名单，都不会移动已注册的会员。
  • 网红本人不变加入名单不改网红自己的上级代理和团队数，网红团队数仍为 0。
  • 代理邀请码不受影响名单只管会员的「邀请好友」路径。代理邀请码（/?vip=邀请码）照常归到对应代理。
  • 所有网红共用一个代理目标代理固定为 5ji-wanghong，不能为每个网红指定代理。要看某个网红带来的人，按「邀请人」筛选。

添加网红

输入会员 ID 后点「校验」，确认账号和上级代理再添加。可试：992107927、992107949、992107926、123。

粘贴会员 ID，用逗号、空格或换行分隔；或上传 .txt / .csv 文件（每行一个 ID，第一列为 ID）。导入前先预览，只有「可添加」的会被加入。
