## 迭代流程

1. 收到意见 → 登记到 PRD「反馈记录」页签（编号 FB-xxx，状态「待处理」），同步 FEEDBACK.md。
2. 确认要改 → 改 PRD 正文 + 原型，版本号 +0.1（3.1、3.2…），在「迭代日志」和 CHANGELOG.md 记一行，回填反馈的处理版本。
3. 原型先提交到本分支；确认后同步到 main（GitHub Pages 只发布 main）。
4. 按群通知规则在 Teams 群发更新通知（先给 Koi 确认全文）。
