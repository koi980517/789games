# 789games · 次日返水与投注奖励活动（别名 1.5%+2%）

活动 1 Cashback：玩家前一天在 Slot / Casino / Arcade / Poker / Fishing / Bingo 的有效投注，次日按档位比例返还。活动 2 Bet Bonus（每日投注奖）：按自然日在参与活动游戏上的有效投注额阶梯发奖。后台可单开活动 1、单开活动 2 或 1+2 同开。

## 在线原型说明（index.html，单文件，无外部依赖）
- 顶部切换「前台 H5 / APP」与「运营后台」；左侧切换身份（普通玩家 / 新玩家）、活动组合（仅 Cashback / Cashback + Bet Bonus / 仅 Bet Bonus）、领取方式（手动 / 自动），可「重新打开 APP」验证弹窗频率。
- 图片素材在 assets/：banner.webp（首页 Banner）、popup.webp（活动弹窗）、model.webp（奖励弹窗人物）、gift.webp（小猫挂件内活动入口）。
- **首页**：按现网 QA 首页结构；Banner 首张 SLOTS CASHBACK。
  - 活动弹窗：整图，不放 PLAY NOW 按钮，点图片任意位置进活动页。频率：每日首次打开 / 每次打开 / 每次进入 Home 页 / 仅一次。原型先裁掉了图底部的按钮，美术需出无按钮版本。
  - 活动奖励弹窗：写死不可配置。手动领取时显示 Claim；自动领取时结算后直接入账，进入 Home 页弹一次到账提示（OK）。
  - 活动入口：放在首页右侧小猫挂件展开后的 JOIN NOW 列表里，排第一个。前端写死，随活动开关显示；原型用 🐱 占位。
- **活动页**：Today / Yesterday、Selected Games、Category、Cashback History、Cashback Rates 表（已移除 Standard Player Tiers 档位表）、Daily Bet Bonus 任务卡（每档 Go / ✓ + 进度条）、Rules 页。
- **后台页签**：活动列表（含创建时间、修改人；状态进行中绿 / 已停用红）/ 活动配置 / 费用使用情况 / 返点核对 / 返水发放 / Push · 短信（二期，置灰）/ 返水记录 / 日报表 / 操作日志。
- **活动配置**（单页编号区块 + 右侧前台实时预览，提交发布需谷歌验证码，原型 000000）：
  - ① 基本信息
  - ② Category
  - ③ Selected Games
  - ④ 返水等级
  - ⑤ 页面素材
  - ⑥ 活动规则页：编辑区右侧实时预览前台 Rules 页，系统追加条款只读展示
  - ⑦ 活动 2 · Bet Bonus：档位配置 + 发放与预算；只自动发放，流水统一 1 倍
  - ⑧ 图标与链接：Selected Games / Category 卡图标与点击链接
- **返水记录**：每日所有用户的记录，按结算日期、会员 ID / 账号、领取状态查询，「明细」弹窗用于核对取整过程。
- **返水发放 › 封控条件**：7 日均值涨幅（新增首日预计返水金额作为基础点）、单用户上限、返水 / 充值占比、同 IP / 设备多账号。
- 金额：当日返水向下取整到 ₱1，低于 ₱1 不发放；数据均为示例，刷新页面即恢复默认。
