# 789games · 次日返水活动（Daily Cashback）

玩家前一天在 Slot / Casino / Arcade / Poker / Fishing / Bingo 的有效投注，次日按比例返还为 Cashback。普通玩家按档位（T1–T10），VIP 固定比例，另有精选组（Featured Group）。
