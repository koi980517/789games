## 1. 概述

玩家当天在 Slot、Casino、Arcade、Poker、Fishing、Bingo 六个分类产生有效投注，次日按比例返还为返水，在活动页或弹窗领取。普通玩家（Standard Player）按当日投注额分档，VIP 按固定比例；运营可另设「Selected Games」组（可整体开关），给指定类型下的指定游戏更高比例。分类（前台叫 Category）及其游戏由后台配置。

### 1.1 全局规则
- 时区统一为 PHT（GMT+8）。
- 当日返水向下取整到 ₱1（₱123.99 发 ₱123），低于 ₱1 不发放；固定规则不可配置。投注额、分类明细保留 2 位小数仅作展示；明日返水、Available 与实际到账均为取整后金额。
- 同一时间只能有 1 个返水活动（共用投注统计、结算、领取、Push / 短信接口）；有进行中活动时不能新建或复制。
- 无「未开始」状态，新建即「进行中」；已结束、已关闭只能查看。
- 前台英文，后台中文。

### 1.2 术语
| 术语 | 含义 |
|---|---|
| Valid Bet 有效投注 | 已结算注单的有效流水，取消单不计入 |
| Tier 档位 | 普通玩家按分类当日有效投注所达门槛（T1–T10）决定比例 |
| Selected Games 组 | 运营挑选的一组游戏，单独比例，所有会员相同 |
| Claim Status | Accumulating → Calculating（23:59:59 锁定）→ Available to Claim → Claimed / Expired |
| Claim Source | Popup、Activity Page、Cashback History、Auto |
| Bonus Turnover | 领取的返水需完成「返水金额 × 倍数」有效投注后才可提现 |

## 2. 业务流程（每日，GMT+8）
| 时间 | 动作 |
|---|---|
| D 日 00:00–23:59:59 | 实时累计各分类 Valid Bet / Rate / Estimated Cashback；Today 页每 10 分钟刷新 |
| D 日 23:59:59 | 锁定当日数据，状态 → Calculating |
| D+1 03:00–04:00（可配） | 返点核对：生成异常名单，运营移除或放行（5.6） |
| D+1 结算时间（必填） | 生成正式返水；跑复查与封控。无异常 → Available to Claim；触发封控 → 暂停并转手动（5.7） |
| D+1 推送时间 | 最多 3 轮 Push + 1 次短信，只发给仍有未领取返水的玩家（5.8） |
| 可领后 N 小时 | 未领 → Expired |

## 3. 返水计算规则
1. 普通玩家：按「分类设置指数 × 当日有效投注」所达档位，整日该分类投注按该档比例计算（非阶梯累进）。最多 10 档，门槛从 ₱0 逐档递增，比例逐档不降。
2. VIP：每分类一个固定比例，首笔起生效，不看档位，不受最高返水上限限制，不随活动开始 / 结束 / 关闭变化。
3. VIP 身份：半月考核（1–15 日、16 日–月底），周期投注 > ₱300,000 成为 VIP；每月 1 日、16 日自动升降级，保级门槛相同。
4. Selected Games 优先（开启时）：组内游戏按组比例，不再按 Category，单笔只计一次；组比例须高于所选类型普通玩家最高档；一个游戏只属于一个组。后台关闭 Selected Games 时，组内游戏回到所属 Category 的档位 / VIP 比例。
5. 手动指定档位：给普通玩家保底档位，实际达更高档按更高档；VIP 不适用；仅当前活动期间有效。
6. 比例上限：≤ 5%，超出不可发布；> 1% 后台蓝色突出显示。
7. 门槛与上限：当日总有效投注 < 最低有效投注不生成；普通玩家单日不超过最高返水上限。
8. 未加入任何返水分类的游戏（见 5.2 ④）、官方已下架的游戏不返水。
9. 当日返水 = 各 Category（含 Selected Games 组）Reward 之和，先套上限，再向下取整到 ₱1；取整后低于 ₱1 不发放。

## 4. 前台（APP，390 × 844）
### 4.1 首页、弹窗与挂件（v1.2，参考返水充返转盘 PRD 3.0）
- 首页按现网 QA 首页结构（https://qa.789node.com/）：顶栏（Logo / 余额 + 充值 / Rewards / 搜索）→ Banner 轮播 → 分类页签（Hot + 返水分类）→ 快捷入口（1.5%+2% Cashback / 2% Instant Return / Rank Cup / Bag）→ 跑马灯 → Recent Games → Hot Games → 底部导航。
- 首页 Banner 首张：PH BIGGEST SLOTS CASHBACK · 1.5% UNLI CASHBACK（assets/banner.webp），点击进活动页。
- 打开 APP：活动弹窗 → 活动奖励弹窗（有可领时）。
- 活动弹窗（专属）：整图直出 MAXIMUM REWARDS · STACK 5 DAILY（assets/popup.webp），图内 PLAY NOW 热区跳活动页，× 关闭；频率后台配（默认每日首次打开）。
- 活动奖励弹窗：人物图 + 彩带「Congratulations !」、标题 DAILY CASHBACK BONUS!、金币 + 可领总额（向下取整）、Claim（一键领取，Claiming… 禁用，成功后余额即时增加，失败可重试）、Cashback Details（跳 History）、Cashback Date（多笔显示「N days · from」）。自动领取时不弹。
- 独立挂件：首页右侧礼盒图 + 角标「1.5%+2%」（前端渲染），点击进活动页；弹窗出现时隐藏，可拖动吸边。
- 不做金币飞入动画，仅余额数字更新。

### 4.2 Daily Cashback 活动页
- 不放顶部 Banner；标题栏右上 ? 进规则页（结算时间、领取有效期只在规则页展示）。Today / Yesterday 切换（Today 预估每 10 分钟更新；Yesterday 可领 + 领取，已领显示 Claimed today）。
- Selected Games（原 Featured Picks）：后台开启时显示，每组一张卡（组名、比例、投注、游戏数、返水），点击进组内游戏页；后台关闭时整块隐藏。
- Category（原 Game Types）：后台可设显示 / 隐藏；按后台「返水分类」逐类一张卡（投注、当前比例、VIP 比例）；普通玩家显示进度条与「再投 ₱X → 下一档比例」。
- History 入口；页底 Cashback Rates 表 + Standard Player Tiers 表。新玩家无记录只显示规则与比例表。
- 视觉：浅紫底 #ECEBFB→#F3F2FB；主色红 #E8253A；Selected Games 卡紫渐变 #4A12B8→#7B2CF0、比例胶囊 #FFD54A；分类卡圆角 14、图标 44×44。

### 4.3 Cashback History 与详情
- 汇总：Available（一键领取）、Claimed、Expired；Tab：All / Available / Claimed / Expired；每天一条，可多条未领。

### 5.2 活动基础设置（v1.3 起合并到「活动配置」单页，见 5.0：① 基本信息 ② Category ③ Selected Games ④ 返水等级）
| 字段 | 规则 |
|---|---|
| 活动开关 * | 关闭后次日 00:00 起不再累计，已生成返水有效期内仍可领 |
| 活动周期 | 开始必填；结束留空 = 长期 |
| 参与人群 | 全部会员；无需 KYC（默认）/ 需要 KYC |
| 返水游戏 | 在「② Category」中按分类指定；未加入分类的游戏不返水 |
| 结算时间 * | 次日 HH:MM，无默认；须晚于返点核对结束；前台只在规则页展示 |
| 最低有效投注 * / 最高返水上限 * | ₱/日；₱/人/日 |
| 发放金额规则 | 固定：向下取整到 ₱1，低于 ₱1 不发放 |
| 领取方式 * | 手动（弹窗 / 活动页 / History）或自动（Claim Source = Auto） |
| 领取有效期 * | 小时，自 Available 起算；前台不显示倒计时，只写在规则页 |
| 返水提现流水倍数 * | 0–50，1 位小数，默认 1 |
| 防重复领取 | 唯一 Claim Status；批量领取锁定；接口幂等 |
| 同 IP / 同设备可领账号数 | 超出后其余账号不可领 |
| 活动总预算 | 用完停止生成并告警 |
| 保存 | 保存并提交审核，通过后次日 00:00 生效 |

- ② 返水等级：A VIP 六分类固定比例（建议不低于普通最高档，否则标红）；B 普通 T1–T10 门槛 + 六分类比例，须连续配置；校验门槛递增、比例不降、>5% 不可发布、>1% 蓝色；发布后前台即时更新。
- ③ Selected Games（v1.3）：整体开关（开启红 / 关闭灰），关闭后前台不显示 Selected Games 区块和比例表 Selected 行，组内游戏按所属 Category 计算，组配置保留。组字段：组名（必填，≤20 字不重名）、图标（1:1，≤500KB）、类型（从启用的 Category 中选，切换类型清空已选游戏）、游戏（从该类型下勾选，已在其他组的置灰）、比例（所有会员相同，须高于所选类型普通玩家最高档）、排序权重（默认 10，越小越前）、有效期。可新增 / 删除组，删除后组内游戏回到所属 Category 比例。
- ② Category（返水分类与游戏，v1.1 可配置）：每个分类可启用 / 停用（停用 = 前台不展示、该类游戏不返水），另有「前台显示 Category 区块」开关；分类可新增、改名（≤16 字不重名）、排序、删除（删除后其游戏不返水；新分类默认各档 0.3%、VIP 1%）。选中分类后从官方游戏库搜索添加游戏，显示每个游戏当前所属分类，可加入 / 移到本分类 / 移出。一个游戏只能属于一个分类；未分类不返水；Selected Games 组内游戏按组比例。分类与游戏决定前台 Category、规则页游戏列表、比例表和返水等级的列。

### 5.6 返点核对
每日 03:00–04:00（可配）；检测对冲、多账号作弊、流水与返点不一致、风控标记；逐条移除 / 确认正常，可撤销；完成核对后其余放行；被移除不生成 Available。

### 5.7 返水发放与封控
- 自动 / 手动发放。封控条件：总额较近 7 日均值涨幅 > X%；单用户 > ₱X；返水 / 当日充值 > X%；同 IP / 设备多账号 > X 组。
- 自动模式触发任一条件 → 预警 → 暂停当日自动发放 → 转手动 → 通知运营；次日恢复自动。
- 通知人员（邮件 / 短信 / 电话）；按日复查报告；当日用户关联明细（留存款项 = 充值 − 提款）；核查并发放弹窗：发放 / 暂停 / 取消。

### 5.8 Push / 短信
- 只发给已结算、有未领且未过期返水的玩家；每轮发送前实时剔除已领取；同批次每人 1 条。
- Push 最多 3 轮（时间晚于结算且递增），内容最多 5 条，变量 {CashbackAmount}、{UserName}；须「保存并发布 Push」；可发测试；按轮次统计送达、打开率等。
- 短信：发送时间、个性化（近 7 日活跃时段）、Smart / Globe 文案 ≤160 字符；立即发送需二次确认；回调 DELIVRD / UNDELIV / EXPIRED / REJECTD。

### 5.9 返水记录
一行 = 玩家 × 统计日；筛选账号、结算日期、活动、Claim Status、Claim Source；列 Settlement Date、活动、账号、Valid Bet、Reward Amount、Claim Status、Expire Time、Claim Time、Claim Source、Batch Claim ID；可导出。

### 5.10 数据统计
一行 = 账号 × 日期 × Category（或 Selected Games 组）× 厂商；汇总有效投注、返水、涉及账号、返水 / 投注；状态 统计中 → 待结算 → 已到账（另有人工审核、未满最低金额）。
