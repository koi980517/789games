## 1. 概述

玩家当天在 Slot、Casino、Arcade、Poker、Fishing、Bingo 六个分类产生有效投注，次日按比例返还一部分作为返水，在活动页或弹窗中领取。所有玩家按当日投注额分档（VIP 固定比例为二期）；运营可另设「Selected Games」组（可整体开关），给指定 Slot 游戏更高比例。分类（前台叫 Category）及其游戏由后台配置。

**活动名称**：次日返水与投注奖励活动（后台菜单、面包屑、活动列表使用）；**别名**：1.5%+2%（后台「① 基本信息 › 活动别名」，≤ 12 字；前台首页快捷入口、小猫挂件内活动入口角标、Hot Games 游戏角标统一显示）。前台活动页标题按活动组合显示 Daily Cashback / Daily Bet Bonus。

### 1.1 全局规则

- 时区统一为菲律宾时间 PHT（GMT+8）。
- **当日返水金额向下取整到 ₱1（₱123.99 发 ₱123），低于 ₱1 不发放；投注额、分类明细保留 2 位小数，仅作展示**。固定规则，不可配置；明日返水、Available 与实际到账金额须一致（均为取整后金额）。
- 同一时间只能有 1 个返水活动。所有活动共用一套接口（投注统计、结算、领取、Push / 短信），有活动「进行中」时不能新建第二个。
- 没有「未开始」（预约）状态，新建后立即进入「进行中」。已结束、已关闭的活动只能查看。
- 前台文案英文；后台中文。

## 2. 业务流程（每日）

D 日投注实时累计，D+1 核对 → 结算 → 推送，超过领取有效期未领即过期。

&#91;embedded content: 活动逻辑图 · D 日累计 → D+1 核对结算 → 按领取方式入账\]

投注先按是否在 Selected Games 决定比例，合计后套上限并向下取整；D+1 核对、校验预算后生成返水，自动领取直接入账，手动领取在有效期内领取，超期为 Expired（未配置有效期则不过期）。

| 时间（GMT+8） | 动作 |
| --- | --- |
| D 日 00:00–23:59:59 | 投注后实时累计各分类 Valid Bet / Rate / Estimated Cashback；前台 Today 页每 10 分钟刷新。 |
| D 日 23:59:59 | 锁定当日数据，状态 → Calculating。 |
| D+1 03:00–04:00（可配） | 返点核对：系统生成异常名单，运营移除或放行（见 5.6）。 |
| D+1 结算时间（必填） | 生成正式返水；跑复查与封控。自动发放：无异常即变为 Available to Claim；触发封控即暂停并转手动（见 5.7）。 |
| D+1 推送时间 | 二期：最多 3 轮 Push + 1 次短信，只发给仍有未领取返水的玩家（见 5.8）；一期不发送。 |
| 可领后 N 小时 | 超过领取有效期未领 → Expired，不再计入 Available；未配置有效期则不过期。 |

## 3. 返水计算规则

1. **普通玩家**：按「分类设置指数 × 当日有效投注」所达档位，**整日该分类投注按该档比例**计算（非阶梯累进）。最多 10 档，门槛须从 ₱0 开始逐档递增，同一分类比例须逐档不降。
2. **VIP（二期）：一期 VIP 与普通玩家一样按档位计算、受最高返水上限限制。二期计划**：每个分类一个固定比例，首笔起生效，不看档位，**不受最高返水上限限制**，长期有效，不随活动开始 / 结束 / 关闭变化。
3. **VIP 身份（二期使用）**：只有 Standard Player / VIP 两种。半月考核（1–15 日、16 日–月底），周期投注 > ₱300,000 成为 VIP；每月 1 日、16 日自动升降级，保级门槛相同。
4. **Selected Games 优先**（开启时）：组内游戏按组比例计算，不再按 Category 计算，单笔投注只计一次。组比例须高于 Slot 普通玩家最高档；只配置 1 组。后台关闭 Selected Games 时，组内游戏回到 Slot 的档位比例。
5. **手动指定档位**：v1.3 移除，只按当日实际投注所达档位计算。
6. **比例上限**：任意比例 ≤ 5%，超出不可发布；> 1% 的比例在后台以蓝色突出显示，防误填。
7. **门槛与上限**：当日总有效投注低于「最低有效投注」不生成返水；普通玩家单日返水不超过「最高返水上限」。
8. **范围**：未加入任何返水分类的游戏（见 5.2 ④）、官方已下架的游戏不返水。
9. **合计与取整**：当日返水 = 各 Category（含 Selected Games 组）Reward 之和，**向下取整到 ₱1**（₱123.99 发 ₱123）；取整后**低于 ₱1 不发放**。先套上限、再取整。

## 4. 前台（APP）

设计稿 390 × 844（iPhone 14 基准）。玩家、新玩家（无历史记录）共用同一套页面。页面见交互原型「前台 H5」页签。

### 4.1 首页、弹窗与挂件（v1.2 参考返水充返转盘 PRD 3.0）

**功能逻辑**

- **首页**：按现网 QA 首页结构（https://qa.789node.com/）—— 顶栏（Logo / 余额 + 充值 / Rewards / 搜索）→ Banner 轮播 → 分类页签（Hot + 返水分类）→ 快捷入口（1.5%+2% Cashback / 2% Instant Return / Rank Cup / Bag）→ 跑马灯 → Recent Games → Hot Games → 底部导航（Home / Chat / Promo / Wallet / Account）。
- **首页 Banner**：轮播首张为「PH BIGGEST SLOTS CASHBACK · 1.5% UNLI CASHBACK」，点击进 Daily Cashback 活动页。
- **打开 APP 顺序**：活动弹窗 → 活动奖励弹窗（有可领时）。
- **活动弹窗（专属）**：整图直出「MAXIMUM REWARDS · STACK 5 DAILY」，图内不放 PLAY NOW 按钮，点击图片任意位置跳活动页；右上 × 关闭。频率后台配（默认每日首次打开）。
- **活动奖励弹窗**：顶部人物图 + 彩带「Congratulations !」；标题 DAILY CASHBACK BONUS!；金币 + 可领总额（向下取整）；主按钮 Claim 一键领取全部有效记录（领取中 Claiming… 禁用，成功后余额即时增加，失败可重试）；次按钮 Cashback Details 跳 Cashback History；底部 Cashback Date（多笔显示「N days · from 日期」）。自动领取时结算后直接入账，玩家进入 Home 页后弹一次同样式的到账提示：金额下方写「Credited to your balance」，主按钮改为 OK（关闭），次按钮 Cashback Details；同一笔到账只提示一次。
- **独立挂件**（v1.4 改为小猫挂件内入口）：不再单独悬浮。放进现网首页右侧「小猫挂件」展开后的 JOIN NOW 活动列表，排第一个：礼盒图 + 红色角标「1.5%+2%」（= 活动别名），点击进活动页。前端写死不可配置，显示与活动状态开关一致：开启显示、关闭自动下线。

### 4.3 Cashback History 与详情

- 顶部汇总：Available Cashback（可领总额 + 一键领取）、Claimed、Expired。

### 4.4 规则页（Rules）

- 入口：活动页标题栏右上 ?。顶部不放 Banner。
- 条款由后台「活动规则页设置」维护，系统固定追加三条：
  - 领取时间：次日 {结算时间}（PHT）结算，可在 {领取有效期} 小时内领取，过期作废（后台未填有效期时显示「可随时领取，不过期」）。
  - 金额：当日返水向下取整到 ₱1（例 ₱123.99 → ₱123），低于 ₱1 不发放。
  - 返水游戏：按分类列出（例 Slot (9 games)），不在列表内的游戏不返水。
- 下方只显示 Cashback Rates 表；Standard Player Tiers 档位表 v1.4 起前端移除（后台「返水等级」配置不变）。

### 5.6 返点核对

- 核对时间：每日 03:00–04:00（可配），核对前一日返点。
- 检测项（可勾选）：对冲投注、作弊（同 IP / 设备多账号）、流水与返点不一致、风控标记。
- 系统生成异常名单，运营逐条「移除返点」或「确认正常」，可撤销；「完成核对，其余放行」后未处理记录按原金额放行。被移除的返点不生成 Available to Claim。
- 汇总：待核对、已移除、移除返点金额、已放行。

### 5.7 返水发放与封控

- 发放方式：自动（复查通过后自动发放）/ 手动（运营查阅复查报告后逐条或批量发放）。
- 封控条件（可勾选 + 阈值）：当日返水总额较近 7 日均值涨幅 > X%（v1.4 新增「首日预计返水金额 ₱X」作为基础点：活动首日无历史数据时以此金额为比较基数；不足 7 日时与已有天数一起算均值）；单用户当日返水 > ₱X；返水总额 / 当日充值总额 > X%；同 IP / 设备多账号领取 > X 组。
- 自动转手动：自动模式下任一条件触发 → 预警 → 暂停当日自动发放 → 切换为手动 → 通知运营核查；次日恢复自动。
- 通知人员：v1.3 移除，封控触发后不单独发邮件 / 短信 / 电话，运营在「返水发放」页核查。
- 返水复查报告（按日）：返水人数、返水总额、充值、提款、留存款项、用户余额、返水 / 充值、即提款占比、复查结论、发放状态。
- 当日用户关联明细：账号、应发返水、当日充值、当日提款、留存款项（= 充值 − 提款）、余额、返水 / 充值、风险提示、状态、发放 / 拒发。
- 点击「核查并发放」弹出问题确认弹窗，确认后可选：发放 / 暂停 / 取消。

### 5.8 Push / 短信（二期）

**二期制作**：一期不开发 Push / 短信，结算后不发送任何 Push / 短信。后台「Push · 短信」页签保留并标「二期」，以下为二期设计。

- 发送条件：已结算、Available Cashback > 0、仍有未领取且未过期记录（短信还需手机号有效）。同一批次每人只发 1 条，多笔合并；金额以发送时为准。
- **已领取的玩家不推 Push、不发短信；每轮发送前实时判定。**
- Push：开关；最多 3 轮，每轮配置次日发送时间 + 推送内容 + 启用；时间须晚于结算时间且递增。推送内容最多 5 条（标题 + 正文），变量 {CashbackAmount}、{UserName}。
- Push 修改后须点「保存并发布 Push」才生效；可「发送测试 Push」。
- 推送效果（按轮次）：应推送、已领取剔除、送达、推送不到（未开通知 / 卸载 / Token 失效）、打开客户端（点击 Push 或推送后 2 小时内打开）、打开率。
- 短信：开关、发送时间、个性化发送（按近 7 日最常活跃时段，无数据按统一时间）、分运营商文案（Smart / Globe，≤ 160 字符，超出按多条计费）。
- 短信发送：名单人数、已领取剔除、已送达、失败；「立即发送短信」需二次确认。名单列：账号、手机号（掩码）、运营商、可领金额、发送内容、回调状态、回调时间 / 说明。
- 短信网关回调：DELIVRD 已送达 / UNDELIV 未送达（空号、停机）/ EXPIRED 超时 / REJECTD 被拒（黑名单、退订）。

### 5.9 返水记录

- **列**：结算日期、会员 ID、账号、玩家类型、有效投注、分类返水合计（2 位小数，超上限标「封顶」）、发放金额（向下取整）、Bet Bonus（活动 2 开启时）、领取状态、领取时间、领取来源、操作「明细」。默认每页 30 条（可选 15 / 50）。
- **明细弹窗（核对用）**：按分类列出有效投注、档位（T1–T10 / Selected）、比例、返水（2 位小数）和合计；底部写出核对过程：分类返水合计 →（低于最低有效投注不返 / 超单日上限按上限）→ 向下取整 → 发放金额，以及 Bet Bonus、状态、领取时间和来源。
