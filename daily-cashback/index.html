本页规则要点

  • 打开 APP：开屏弹窗 → 返水领取弹窗（有可领时）。
  • 自动领取时结算后直接入账，不弹领取弹窗。
  • 普通玩家：整日该分类投注按所达档位比例计算（非累进）。
  • VIP：固定比例，不受最高返水上限限制。
  • 精选组内游戏按精选比例，不再按分类计算。
  • 当日返水向下取整到 ₱1（₱123.99 → ₱123）；低于 ₱1 不发放。
  • 活动页不放顶部 Banner；结算 / 领取时间只写在规则页（右上 ?）。
  • 返水分类及每类包含的游戏由后台「④ 返水分类与游戏」指定。
  • 后台改分类 / 游戏 / 比例后，前台即时更新（同一页面内）。
