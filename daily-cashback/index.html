本页规则要点

  • 打开 APP：活动弹窗（整图，PLAY NOW 进活动页）→ 活动奖励弹窗（有可领时）。
  • 首页右侧独立挂件「1.5%+2%」，首页 Banner 首张为 Slots Cashback。
  • 自动领取时结算后直接入账，不弹活动奖励弹窗。
  • 普通玩家：整日该分类投注按所达档位比例计算（非累进）。
  • VIP：固定比例，不受最高返水上限限制。
  • Selected Games 组内游戏按组比例，不再按 Category 计算；后台可整体关闭。
  • 活动页「Category」区块与分类、游戏均由后台配置。
  • 当日返水向下取整到 ₱1（₱123.99 → ₱123）；低于 ₱1 不发放。
  • 活动页不放顶部 Banner；结算 / 领取时间只写在规则页（右上 ?）。
  • Category 及每类游戏、Selected Games 组（类型 / 游戏 / 比例 / 图标）、返水等级、手动指定档位（juan88）、页面素材、规则条款、活动开关均由后台配置。
  • 后台任何配置修改后，前台与后台右侧预览即时生效（同一页面内，刷新恢复默认）。
