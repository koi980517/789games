# 【789games】当日返水活动（2% Instant Return）

玩家当天在指定 Slots 游戏上完成「充值 + 投注」档位任务，每完成一档即可在活动页立即领取返水；默认 8 档，单人单日最高 ₱15,000，每天 00:00（GMT+8）重置。只作用于 789games。

## 范围

- 前台：开屏弹窗（P1）、首页入口卡（P2）、活动页档位任务（P3）、规则弹窗（P4）、指定游戏页（P5）、领取反馈（P6）、提现页流水提示（P7）
- 后台：活动中心 → 当日返水活动：活动列表 / 活动设置 / 返水档位 / 发放与风控 / 黑名单 / 返水记录

## 核心规则摘要

- 逐次任务：同一时间 1 个激活档，充值 + 指定 Slots 有效投注同时达标即可领取；超出部分不结转。
- 当日奖池上限：超出整笔拦截（POOL_FULL），次日 00:00 重开。
- 发放：自动 / 手动；熔断条件命中当天转手动；关联账号命中进复查队列；超单日上限自动列入黑名单。
- 档位修改次日 00:00 生效，其余设置即时生效；领取接口按 userId 加锁 + requestId 幂等。
