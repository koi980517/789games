## 1. 背景与范围

玩家当天在指定 Slots 游戏上完成「充值 + 投注」任务，每完成一档就能在活动页立即领取返水（Instant Return），默认 8 档，每天 00:00（GMT+8）重置。789games 已关闭主站全部返水（GAM-5），次日返水要等到 D+1 才到账，缺一个当天就能拿到、引导玩家逐档冲高的激励。

**目标**

- 提升 Slots 当日充值与投注：引导玩家从 T1 逐档往上完成。
- 即时到账：补足次日返水反馈慢的问题。
- 成本可控：累计返还率默认 ≤ 2%；通过当日奖池上限、熔断、复查、黑名单控制套利。
- 运营 5 分钟内配好一个活动；奖池满 / 熔断时自动拦截并通知到人。

| 包含 | 不包含 |
| --- | --- |
| 前台：开屏弹窗、首页入口卡、活动页（档位任务）、规则弹窗、指定游戏页、领取反馈、提现页流水提示 | 次日返水活动（Daily Cashback）——另见其 PRD；本文只在提现流水提示处写两者共用 |
| 后台（活动中心 → 当日返水活动）：活动列表、活动设置、返水档位、发放与风控、黑名单、返水记录 | 非 Slots 游戏的投注、返点按厂商 / 分类配置（属次日返水） |
| 领取接口、奖池拦截、熔断 / 复查、预警通知（邮件 / 短信 / 电话） | Push / 短信触达（当日返水不做结算后触达） |

**适用范围**：只作用于 789games（与 789bingo 共用后端，按站点隔离，789bingo 不展示、不计算）；币种 PHP（₱）；前台语言 English；端：H5 / iOS / Android；时区 GMT+8。

## 3. 前台流程

玩家从开屏弹窗或首页入口进入活动页，当前激活档累计当天充值 + 指定游戏投注，达标后点 Claim，服务端校验后入账、转待审核或拦截。设计基准 390 × 844。

```
开屏弹窗 / 首页入口 → 活动页·激活档累计 → 本档达标？ ─否→ 继续累计
                                              └─是→ Ready → 点 Claim → 服务端校验（资格·奖池·风控）
                                                                         ├─ 自动入账（生成 1x 流水，档位 Claimed）
                                                                         ├─ 转人工审核（手动发放 / 命中复查，Under review）
                                                                         └─ 拦截不发放（奖池已满 / 黑名单 / 已过期）
00:00（GMT+8）进度清零，未领作废
```

| 编号 / 页面 | 触发条件 | 页面表现 |
| --- | --- | --- |
| P1 开屏弹窗 | 活动开启 + 在活动时间内 + 非黑名单 + 后台弹窗开关开；每天首次启动（App 回前台算启动），服务端按 userId + 日期记曝光 | 全屏遮罩 + 竖版海报；CTA 默认 PLAY NOW（后台可改），有可领档时改为 CLAIM ₱X NOW；点海报 / 按钮跳后台所选目标（Slots 分类页 / 活动详情页）；点 ✕ 关闭 |
| P2 首页入口卡 | 同 P1 资格（不含弹窗开关） | 与 Daily Bonus 卡并列横滑；有可领档 = Claim now，否则 = Deposit & Play；点击 → P3 |
| P3 活动页 | 从 P1 / P2 / Promo 列表进入 | 头图（右上 ? → P4）；Today 区：今日可领合计 + 距 00:00 倒计时 + 一键 Claim；档位卡列表（状态见下表）；底部固定条 Total Bonus ₱X / My Bonus ₱Y |
| P4 规则弹窗（Details） | P3 头图「?」 | 底部弹层；REWARDS 表（Deposit / Bet / Bonus / 累计 Total Bonus，读后台档位）+ RULES 6 条固定文案 |
| P5 指定游戏页 | P3 Bet 行「Go」，后台「Go 跳转」= 指定游戏列表 | 顶部说明 + Today's eligible bet: ₱X；3 列宫格，顺序同后台，角标 COUNTS ✓；点击直接进游戏。后台选「单款游戏」时跳过本页直接进该游戏 |

| P7 提现页流水提示 | 有未完成的返水流水 | 提现金额输入框上方浅黄提示条，可展开逐笔进度；与 Daily Cashback 共用，金额为两者合计 |

**弹窗队列**：P1 进前端统一弹窗队列 `fullModalList`，建议排在登录促销三个（`promo-login-whitelist` / `promo-login` / `loss-promo`）之后、`gold` 之前；不与 21+ / 协议弹窗叠加；与 Daily Cashback 领取弹窗同时满足时的先后见待确认 1。

**进度刷新**：进入页面、回到前台、充值到账 / 注单结算后刷新（推送还是轮询见待确认 4）。

## 4. 核心规则：档位、奖池与流水

默认 8 档，单人单日最高 ₱15,000，累计返还率从 T1 的 2.00% 逐档降到 T8 的 0.84%（示例值，待运营确认）。

| Tier | 本次充值 ≥ | 本次流水 ≥ | 返水 | 累计返水 | 累计返还率 |
| --- | --- | --- | --- | --- | --- |
| 1 | ₱50 | ₱100 | ₱2 | ₱2 | 2.00% |
| 2 | ₱200 | ₱1,000 | ₱13 | ₱15 | 1.36% |
| 3 | ₱500 | ₱5,000 | ₱60 | ₱75 | 1.23% |
| 4 | ₱2,000 | ₱20,000 | ₱225 | ₱300 | 1.15% |
| 5 | 不限 | ₱50,000 | ₱450 | ₱750 | 0.99% |
| 6 | 不限 | ₱200,000 | ₱2,250 | ₱3,000 | 1.09% |
| 7 | 不限 | ₱500,000 | ₱4,500 | ₱7,500 | 0.97% |
| 8 | 不限 | ₱1,000,000 | ₱7,500 | ₱15,000 | 0.84% |

累计返还率 = 累计返水 ÷ 累计流水（前 N 档流水门槛之和）。

| 项目 | 规则 |
| --- | --- |
| 档位数 | 1–99；校验：流水门槛严格递增、充值门槛不递减、返水金额为 ≥ ₱1 的整数；任一档累计返还率 > 2% 标红并二次确认 |
| 充值条件开关 | 关闭时所有档只看流水，前台只显示 Bet 进度 |
| 投注口径 | 只算指定 Slots 游戏的有效投注，100% 计入；跨 00:00 的注单按结算时间归日 |
| 充值口径 | 到账时计入；加赠、存款券、奖励不计 |
| 单人单日上限 | = 各档返水金额之和，只读；不能超过当日奖池上限 |
| 当日奖池 | 领取时校验「今日已发放 + 本次 ≤ 上限」，超出整笔拦截（不拆分），返回 POOL_FULL；次日 00:00 重开；被拦截的档不补发；人工审核通过的单同样受上限约束。示例 ₱3,200,000，前台显示 Total Bonus ₱3.2M（M / K 缩写） |
| 提现流水 | 返水金额 × 倍数（示例 1x），只算指定游戏有效投注；未完成时该笔返水不可提，本金可提 |
| 金额精度 | 2 位小数（原型部分处显示 3 位，以本文为准）；前后台一致 |

## 5. 后台配置

菜单路径：活动中心 → 当日返水活动（新增），6 个页签：活动列表 / 活动设置 / 返水档位 / 发放与风控 / 黑名单 / 返水记录。视觉沿用现网后台外壳。

### 5.1 活动列表

- 筛选：活动名称 / 编号（模糊）、状态（全部 / 进行中 / 未开始 / 已结束 / 已关闭 / 草稿）；按钮：搜索、导出、+ 新建。
- 统计卡：活动数（进行中 / 全部）、累计参与人次、累计投注、累计已发放返水、返水 ÷ 投注。
- 列：编号、活动名称、活动周期、状态、参与人数、计入流水、已发放返水、未领取返水、返水 ÷ 投注（> 2% 标红）、领取率、操作。
- 操作：展开详情（配置摘要、日均参与、人均返水、预算使用、创建 / 审核人、活动天数、备注）、编辑、数据、结束（仅进行中，二次确认）、删除（仅草稿）。已结束的只能「查看设置」（只读）。
- 编号系统生成（IR-xxx），唯一不可改；新建先存草稿，填完设置和档位后发布为「未开始」。
- **修改进行中的活动**：红色警示框列出各设定项的当前值和生效方式（档位类次日 00:00，其余即时）；每次修改生成修改编号，写入「修改记录」（修改编号 / 时间 / 修改人 / 内容 / 生效时间）。

### 5.3 返水档位

- 「返水次数」1–99，点「应用」生成行数；也可「+ 增加一次」/ 行内删除（至少保留 1 次）。
- 「启用充值条件」开关；每行：本次充值 ≥（留空 = 不限）、本次流水 ≥、返水金额；累计返水、累计返还率为只读计算列。
- 校验见第 4 节；「保存并发布」后次日 00:00 生效。

### 5.4 发放与风控

1. **状态条**：自动发放中 / 已熔断转手动 / 手动发放中 / 已人工恢复；显示今日已发放、前 7 日均值、复查命中人数、预算使用率；熔断后出现「核查完成，恢复今日自动发放」。
2. **当日奖池监控**：使用率（进度条 + 预警 / 严重刻度）、今日已发放 / 剩余、领取人数 / 笔数、超额拦截、预计耗尽（剩余 ÷ 近 1 小时速度）；报警阈值预警 ≥ 80%、严重 ≥ 95%（示例），100% 系统拦截。
3. **发放方式**：自动 / 手动；熔断后恢复：次日 00:00 自动恢复 / 需人工恢复。
4. **熔断条件**（每条可单独开关，开启后阈值必填；任一达到 = 预警 + 停止当日自动发放 + 通知）：当日发放 ≥ 前 7 日均值 × 2；返水 ÷ Slots GGR ≥ 40%；复查命中人数 ≥ 50；单小时发放 ≥ ₱150,000；奖池使用率 ≥ 90%（均为示例值）。
5. **自动列入黑名单**：单人当日领取 > 单人单日上限时，默认将该玩家列入活动黑名单（可关闭）。
6. **复查规则（单笔）**：当前启用 1 条——关联账号：同 IP / KYC 当日领取账号 ≥ 3；命中不自动入账、进复查队列。风险标签点开看判定条件 / 风险说明 / 处理建议。原型里「单人高额」「新注册高档」已写说明但未启用（待确认 8）。
7. **预警通知人员**：邮件 / 短信 / 电话总开关；人员表（姓名、角色、邮箱、手机号含区号、渠道、接收级别、启用）；编辑 / 测试通知 / 删除；短信 / 电话失败 5 分钟后重试 1 次；无人员时只写日志。
8. **复查 / 待审核队列**：领取时间、账号、次数、返水金额、当日充值 / 提款、当前余额、留存款项（充值 − 提款）、当日流水、关联号、风险标签、操作（通过 / 拒绝 / 限制）；支持批量。「限制」= 加入黑名单。
9. **预警日志**与**奖池日报**（按日，近 7 日合计，可导出）。

### 5.5 黑名单

- 添加：用户 ID（多个，空格 / 逗号 / 换行分隔，自动去重，已在名单的跳过）、原因（关联账号 / 多开、套利行为、新注册套利号、内部 / 测试账号、其他）、期限（永久 / 至某日）、备注。
- 名单列：用户 ID、原因、备注、来源、添加时间、到期、状态、操作（移除）；搜索、批量移除。
- 效果：前台不显示入口与弹窗、投注不累计、不能领取，即时生效；已领取的不追回；到期自动解除，已解除记录保留 30 天。
- 操作日志：添加 / 移除 / 自动列入 / 到期解除，记录时间、操作人、类型、说明。

### 5.6 返水记录

- 一行 = 一次领取（某账号某天某一档）。筛选：时间（今天 / 昨天 / 近 7 天 / 全部 / 自定义）、活动、状态（已发放 / 待审核 / 已拒绝 / 已作废）、账号。
- 统计卡：笔数 / 人数、已发放、待审核、已拒绝 / 作废、手动发放占比。
- 列：领取时间、账号、活动、第 N 次、返水金额、当日充值、当日流水、发放方式、状态、审核人。分页 10 / 20 / 50；导出 CSV 按当前筛选（≥ 1 万条异步）。

## 8. 接口与错误码

接口路径为建议命名，以后端为准。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/activity/instant-return/info | 活动状态、标题、档位配置、奖池展示值、弹窗配置；黑名单用户返回 visible=false |
| GET | /api/activity/instant-return/progress | 当前激活档、各档状态与进度、今日可领、My Bonus、奖池是否已满 |
| GET | /api/activity/instant-return/games | 指定游戏列表 + 今日指定游戏有效投注 |
| POST | /api/activity/instant-return/claim | 入参 tiers[]（单档或全部）+ requestId；返回每档结果 |
| GET | /api/activity/instant-return/turnover | 提现页流水提示（与 Daily Cashback 合并返回） |

**claim 处理顺序**：校验登录 / 活动状态 / 黑名单 → 按 userId 加锁 → 校验档位已完成且未领（账号 + 日期 + 档位唯一）→ 校验并占用奖池 → 先写领取记录（状态）→ 判断发放方式 / 复查规则 → 入账并生成流水要求，或转待审核 → 更新奖池统计、判断熔断与自动列黑。同一 requestId 重复请求返回首次结果。

| 错误码 | 场景 | 前台提示 |
| --- | --- | --- |
| POOL_FULL | 今日已发放 + 本次 > 奖池上限 | Today's bonus pool is fully claimed. Try again after 00:00. |
| USER_BLOCKED | 在黑名单 | Your account is not eligible for this promotion. |
| TIER_NOT_COMPLETED | 服务端校验未达标 | 刷新进度，不弹错误 |
| TIER_ALREADY_CLAIMED | 重复 / 并发领取 | 按已领取刷新，不弹错误 |
| PROMO_INACTIVE | 活动关闭或不在时间内，且无当天已完成档 | This promotion has ended. |
| PERIOD_EXPIRED | 跨 00:00 领取前一天的档 | This bonus has expired. |
| PENDING_REVIEW | 手动发放 / 命中复查（返回成功 + 状态） | Submitted ₱X for review · credited after approval |
| SYSTEM_ERROR | 超时 / 网络 / 未知 | Something went wrong. Please try again.（按钮变 Retry） |

成功入账：全屏动效约 2.6s「Instant Return Claimed! ₱X」「Added to your balance · 1x turnover required」，余额旁 +X 约 3.4s。提现页提示：「₱X cashback hasn't met the 1x turnover yet. Bet ₱Y more to withdraw it.」；全部完成「All claimed cashback has met the 1x turnover.」。

## 10. 验收要点

- [ ] 逐次任务：上一档未完成时下一档 Locked；超出部分不结转；充值留空档只看流水
- [ ] 口径：非指定游戏、作废 / 取消注单不计；加赠不计充值
- [ ] 00:00 跨天（GMT+8）：进度清零、未领作废、跨天注单按结算时间归日、23:59:59 点 Claim 与 00:00:01 到达服务端的处理
- [ ] 并发与幂等：连点 / 单档与一键同时点 / 同 requestId 重放，只发一次
- [ ] 奖池：临界值整笔拦截不拆分；Pool Full 按钮与红条；审核通过单仍受上限；次日重开
- [ ] 熔断：各条件触发后切手动、通知到人；人工恢复 / 次日自动恢复
- [ ] 复查：关联账号命中进队列；通过入账、拒绝显示 Not approved、限制加黑名单
- [ ] 黑名单：即时隐藏入口与弹窗、停止累计；到期自动解除；超单日上限自动列入
- [ ] 配置生效：档位次日 00:00，其余即时；修改记录与操作日志正确
- [ ] 活动关闭 / 到期：入口弹窗隐藏，当天已完成未领的仍可领
- [ ] 弹窗：每日首次、不与 21+ 叠加、队列位置正确
- [ ] 站点隔离：789bingo 不展示、不计算
- [ ] 多端：H5 / iOS / Android 逐端；金额 2 位小数前后台一致

## 12. 风险与依赖

| 等级 | 类别 | 风险 | 应对 |

| 高 | 资金 | 并发领取 / 奖池临界超发 | userId 加锁 + requestId 幂等 + 奖池原子占用；上线前压测 |
