# 789games / 789bingo · 弹窗中心（活动弹窗整合 · 按钮跳转配置 · Home 登录弹窗队列）

后台「活动配置」新增菜单【弹窗中心】：把所有活动弹窗和 Home 活动弹窗列在一张表里，每个按钮的跳转从统一的「跳转目标库」下拉选择（H5 / App 可分开，支持指定游戏），并把登录后进 Home 的弹窗顺序、开关、频率、单次上限从代码写死改为后台可配。两站各一套配置。

## 核心规则一览

- **范围**：弹窗中心只管「展示与跳转」，活动规则、奖励、名单仍在各活动菜单；弹窗由开发注册，运营不能在此新增或删除。
- **按钮**：跳转按钮配目标和文案；动作按钮（GO / Claim）动作不变，只配「成功后跳转」；合规 / 系统按钮只读。
- **跳转方式**：关闭弹窗（默认）/ 站内页面（只能从目标库选）/ 指定游戏 / 活动详情 / 外部链接；默认两端同一目标，可分端。
- **跳转目标库**：弹窗中心、首页小框、Home 轮播共用；只能停用不能删除，停用后引用处按关闭弹窗兜底。
- **队列**：强更 > 协议 > 21+ 固定置顶、不计上限；其余只按序号（无插队例外），逐个判断开关 → 频率 → 活动资格 → 上限，串行弹出。
- **频率**：每次进入 / 每天一次 / 活动期间一次 / 永久一次；登录用户按 userId 计，游客按设备计，GMT+8 切日。
- **单次上限**：默认不限（保持现网），可设 1–10。
- **即时弹窗**（充值失败、Invite Rewards 等）：不进队列，但等当前弹窗关闭后再弹，不叠加。
- **上线初始化**：各站现网顺序与默认跳转，上线当天前台零变化；唯一有意变更是 789bingo 旧版砸金蛋不再插队。
