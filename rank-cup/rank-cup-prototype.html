首页入口：三格广告位

  • Rank Cup 出现在首页三格中的任意一格即可，位置不指定；图中放在中间一格仅为示例。点红框进入排行榜，左上角 ‹ 回首页。
  • 配置走「活动配置 › 首页小框广告位」：新增 Rank Cup 素材并开启，放在哪一格由运营决定。
  • 跳转：H5 /promo/leaderboard（默认打开 VIP Tab）；App 需新增 target=leaderboard，未支持前用 promo_detail + activity_id。游客先登录再跳转。
  • ₱300,000 写在图上，对应 VIP 周榜第 1 名奖金；奖金改了要换图。
  • 素材：现网格子是 118×78，收到的图绿色部分偏矮（约 66 高），和左右两格不齐；请设计按 118×78 的 3 倍图出（≤500KB）。

首页入口二：右侧挂件

  • 在现有首页挂件（Lucky Spin / Daily Gift / Invite Now）里加一个 Rank Cup（虚线框）。挂件最多同时显示 3 个，超过时每 3 秒自动轮播。
  • 排序先按资格分档：有资格有奖可领 > 有资格 > 无资格；同档按后台排序。
  • 角标：上期获奖且奖金已在 10:00 自动到账（当天内）→ Won + 抖动，点击打开 Previous 查看；已上榜 → 我的名次；未上榜 → Join；VIP 不够 → 置灰排最后。
  • 挂件沿用现网位置，在右侧。Hide 后收起为现网的猫抱礼盒图标（红色 !），点击再展开；可拖动、吸附左右边缘。
  • 图标和名称为前端默认图片，后台只控制开启 / 关闭（「排行榜活动 › 活动列表」顶部「入口设置」）。
  • 试一下：右边「我的状态」切换，或点挂件的 Won 进入 Previous 查看后回首页，看挂件角标变化。

排行榜页

  • 顶部 Tab = 一个榜单：VIP（综合榜：Slot + 真人，VIP 等级门槛）+ 各厂商榜 JILI / PG / FC / PP / OTG。Tab 名称和顺序在后台配置，横向滑动。
  • 主视觉：活动名、活动日期、Ends in（到本期结束的倒计时，GMT+8）。
  • Previous / Current：Current 为本期实时（每 5 分钟刷新），Previous 为上一期最终结果（奖金已于 10:00 自动到账，无需领取）。
  • 领奖台 Top3：头像、脱敏昵称、Bet、该玩家最近玩的游戏（本榜计分范围内，带 ▶）、奖金。点游戏图标直接进入该游戏；游客先登录，游戏维护中提示维护。下面是 Rank / Player / Bet / Bonus 列表。
  • 底部紫色 ME 行常驻：我的名次（未上榜显示 --）、我的有效投注、预估奖金。上方一行提示与上一名 / 进入奖励区的差距。
  • 底部悬浮游戏框：复用活动详情页现有的「PLAY MORE! WIN MORE」模块（游戏卡 + PLAY，横向滑动）；展示本榜计分范围内的游戏，点 PLAY 直接进游戏。ME 行贴在它上方。
  • 同一笔注单可以同时计入 VIP 榜和对应厂商榜。

发奖到账弹窗 + 通知

  • 自动到账：10:00 发奖时直接入账余额，不需要用户在线或领取；长期没登录的用户也照常到账。
  • 到账弹窗：发奖后用户第一次进入首页或排行榜页自动弹出，列出本次到账的奖励和合计。看过一次就不再弹（按用户 + 发奖批次记录）；离开期间累积的多期奖励合并在一个弹窗里。View Results 打开对应 Tab 的 Previous。
  • 与首页其他弹窗同时出现时，到账弹窗优先。VIP 等级不足 / 没获奖的用户不弹。
  • 推送 / 短信提醒：二期，一期不做（见「规则与口径」末尾「二期」）。

模拟

前后台已打通：后台的配置会直接驱动前台——新增并发布的榜单出现在顶部 Tab（按排序）；开启 / 关闭、名称、活动类型、日期（未开始显示 Starts in）、排名指标、奖池与名次占比、VIP / 最低投注门槛、稽核倍数、指定游戏（领奖台游戏图标、底部游戏框、规则文案）、底部游戏框开关、首页挂件开关，都即时同步。后台列表和编辑页可点「前台预览」直接跳到该榜。头像为示例，游戏图无素材时用厂商色块占位。
