## 核心规则

- 层级：投注站 → 投流总代理 → 投流一级代理 → 会员 → 会员带来的 L1～Ln。
- 投流总代理只能由运营建；投流一级代理由运营（主后台）或投流总代理自己（投流代理端）建，一次 1～1000 个。
- 邀请码 = 前缀字母 + 序号数字，不区分大小写，全局唯一；已占用自动顺延；不够时整批不生成。
- 会员三种来源：投流一级代理链接注册、投流一级代理绑定已有会员 ID、本线会员邀请好友；上级代理都 = 该投流一级代理，不设层级上限。
- 绑定会员：每个投流一级代理累计绑定 1～10 个投流方自己的账号；账号上一级须是非会员、所属大代理须是官方 10 个大代理之一（在现有大代理系统里标记，投流代理模块不设名单页，投流方看不到）；不可改绑。
- 会员新增 tldl 字段：投流总代理、投流一级代理、层级 L1～Ln、来源、邀请人、当时邀请链接、邀请码、路径、归属时间；与现网 super_id / query_code 两边都写。
- 投流核验：写入时拦截重复（邀请码、账号、链接、会员归属、绑定超限 / 不合规），每 10 分钟巡检，发现问题后台告警（C1～C8）。
- 只对带「投流代理线」标识的投流总代理生效，其他代理线不变（会员邀请仍进 5-ji-agent）。
- 导出固定字段：投流一级代理 ID、账号、创建时间、链接。
- 投流总代理只能看、只能操作自己名下的投流一级代理，服务端校验。
