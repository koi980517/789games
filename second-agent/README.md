## 核心规则

- 层级：投注站 → 大代理（投流方）→ 代理 → 会员 → 会员带来的 L1～Ln。
- 大代理只能由运营建；代理由运营（主后台）或大代理自己（代理端）建，一次 1～1000 个。
- 邀请码 = 前缀字母 + 序号数字，不区分大小写，全局唯一；已占用自动顺延；不够时整批不生成。
- 会员三种来源：代理链接注册、代理绑定已有会员 ID、本线会员邀请好友；上级代理都 = 该代理，不设层级上限。
- 绑定会员：会员直属上级须在「官方大代理名单」（后台指定 10 个大代理 ID）内；先校验后绑定；不可改绑；绑定前数据留原线。
- 只对带「二级代理线」标识的大代理生效，其他代理线不变（会员邀请仍进 5-ji-agent）。
- 导出固定字段：代理 ID、代理账号、创建时间、代理链接。
- 大代理只能看、只能操作自己名下的代理，服务端校验。
