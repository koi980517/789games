现网读取（2026-11-11 QA 实测 + 知识库）

• 现网层级：投注站 → 大代理 →（代理，可多层）→ 会员；大代理也能直接拉会员
• 只有代理邀请码（域名/?vip=码）能把人放进代理树
• 会员「邀请好友」链接（/invite/玩家ID）拉来的人统一进 5-ji-agent，只靠「邀请人」字段关联
• 网红代理名单只对名单内的人生效，二级起回 5-ji-agent
• 直属代理 / 直属会员 = super_id 一层；团队数 = query_code 整棵树
• 后端已有「普通邀请」路径：继承邀请人的上级代理
• 本模块的「投流总代理」沿用现网大代理身份，「投流一级代理」沿用现网代理身份
本原型的取舍

• 命名：模块叫「投流代理」，两级分别叫「投流总代理」「投流一级代理」；投流总代理只能由运营建
• 投流一级代理一层，运营或投流总代理（投流代理端）都能批量生成，两边共用同一套表单
• 本线会员带来的人不再进 5-ji-agent，全部算在投流一级代理下
• 绑定会员：先校验后绑定，只绑可绑的；不可改绑；不再要求上级为官方大代理
• 统计：新增一张「投流代理线汇总」
• 示例数据均为虚构，非线上配置；时间都是 GMT+8

投流代理逻辑（一句话版）

• 一条线 = 投流总代理 → 投流一级代理 → 会员 → L1～Ln
• 会员三种来源：①投流一级代理链接注册 ②投流一级代理绑定已有会员 ③本线会员邀请好友
• 三种来源的上级代理都 = 该投流一级代理；L1～Ln 不设层级上限
• 只对带「投流代理线」标识的投流总代理生效，其他线不变
• 归属在注册 / 绑定那一刻决定，之后不自动变
• 绑定前的数据留原线，绑定后的算本线，报表回刷不漂移
• 投流总代理只看、只操作自己下面的投流一级代理，服务端校验
