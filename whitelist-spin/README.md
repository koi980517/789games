# 789games · 白名单转盘（Whitelist Lucky Spin）

活动中心新增独立活动【白名单转盘】。整体复刻现有【老用户充值转盘】的配置、转盘展示、奖励发放和活动统计。

主要区别：用户不再通过充值获得转盘次数。运营在活动配置里导入手机号白名单（沿用现有导入逻辑），名单内用户各得 1 轮转数；每一转可设为免费或付费（付费转沿用老转盘充值配置表）。

## 核心规则一览

- **转数**：每人一轮 N 转，逐转设为免费或付费；免费转用免费转盘配置，付费转沿用老转盘充值配置表（充值到账后按档位抽）。
- **白名单**：在活动配置里按手机号 CSV 导入，须先保存活动；名单内用户各得 1 轮转数。
- **盘面**：前台固定 10 格，付费档位奖励金额从 10 格中选。
- **删除活动**：只有已关闭、且没有未使用次数的活动可以删除，删除为软删除。
- **抽奖顺序**：抽奖接口先扣次数，再返回结果。
