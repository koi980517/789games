# 789games · 白名单转盘（Whitelist Lucky Spin）

活动中心新增独立活动【白名单转盘】。整体复刻现有【老用户充值转盘】的配置、转盘展示、奖励发放和活动统计。

主要区别：用户不再通过充值获得转盘次数。次数由运营在后台按 User ID 直接发放，并指定次数类型（免费 / 充值）。

## 核心规则一览

- **盘面**：前台固定 10 格。每格在后台配置类型（免费 / 充值）、金额和概率。
- **命中范围**：免费次数只在免费格里抽，充值次数只在充值格里抽。两组概率各自合计 100%。
- **发放**：按 User ID 发放，支持单个和批量（CSV）。每次填写次数、次数类型和备注。
- **次数消耗**：多条发放记录先发先用。
- **失效**：活动结束后，未使用的次数失效。
- **作废**：可以作废记录中剩余的次数，已中奖的金额不回收。
- **删除活动**：只有已关闭、且没有未使用次数的活动可以删除，删除为软删除。
- **抽奖顺序**：抽奖接口先扣次数，再返回结果。
