# 789games · 白名单转盘（Whitelist Lucky Spin）

活动中心新增独立活动【白名单转盘】。整体复刻现有【老用户充值转盘】的配置、转盘展示、奖励发放和活动统计。

主要区别：用户不再通过充值获得转盘次数。运营在活动配置里导入手机号白名单（沿用现有导入逻辑），名单内用户各得 1 轮转数；每一转指定使用哪个免费转盘（可配置多个转盘概率）；彩金流水可限定游戏类别或指定游戏。

## 核心规则一览

- **转数**：每人一轮 N 转，全部免费；逐转指定用「免费转盘1 / 2…」。
- **多转盘**：每个转盘独立 10 格奖励 + 概率（合计 100%），不同底色区分。
- **预算**：接入顶部预算告警（消耗 ≥ 70%）；剩余预算 < 最小奖励时活动自动关闭。
- **权限**：活动中心新增 101419 白名单转盘及 8 个按钮权限码。
- **流水**：倍数 + 计入流水的游戏（全部 / 6 类分类 / 指定游戏三级选择）。
- **白名单**：在活动配置里按手机号 CSV 导入，须先保存活动；名单内用户各得 1 轮转数。
- **删除活动**：只有已关闭、且没有未使用次数的活动可以删除，删除为软删除。
- **抽奖顺序**：抽奖接口先扣次数，再返回结果。
