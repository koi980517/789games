## 1. 背景与范围

活动中心新增独立活动「白名单转盘」：运营导入手机号白名单，名单内用户直接获得一轮免费转盘次数，无需充值。

现有「老用户充值转盘」的次数来自充值；现网「白名单奖励档位」只是换一套档位，用户仍需充值，满足不了召回、补偿、VIP 关怀等直接发放的场景。新活动复刻老用户充值转盘的配置、盘面、发奖和统计，但配置、预算、统计都独立；原活动保持不变。

| 包含 | 不包含 |
|---|---|
| 活动中心新增「白名单转盘」菜单，页签：活动配置、活动统计、操作日志 | 修改原老用户充值转盘 |
| 转数设置、多转盘（每个转盘独立奖励 + 概率）、流水指定类别 / 游戏 | 付费转、充值档位（已全部移除） |
| 创建 / 编辑页内按手机号 CSV 导入白名单（沿用现有导入逻辑） | 单独的「白名单发放」页签、按 User ID 单个发放 |
| 顶部预算告警、预算不足自动关闭、权限码 | 未登录用户可见的盘面 |
| 前台入口、获得次数提示、10 格转盘、中奖弹窗、中奖轮播 | 返水奖励 |

## 2. 后台：活动配置

菜单：活动中心 › 白名单转盘；activityType 新建 WHITELIST_SPIN，接口前缀 /api/admin/activity/whitelistSpin。

### 2.1 活动列表

- 筛选：活动名称、创建人、状态。
- 列：序号、活动编号、活动名称、活动类型、开始 / 结束 / 创建时间、活动总预算、已使用预算、白名单人数（新增）、已抽次数（新增）、创建人、状态开关、操作。
- 状态开关：关闭后已发未用次数不可抽，前台入口隐藏；切换前二次确认。
- 删除（新增）：仅「关闭」且无未使用次数的活动可删，否则置灰并悬停提示原因；二次确认后软删除，发放、抽奖、统计和操作日志保留可查。

### 2.2 创建 / 编辑活动

| 分组 | 字段 | 说明 |
|---|---|---|
| 展示 | 活动展示开关 | 开启后仅剩余次数 > 0 的白名单用户可见入口；未登录一律不展示 |
| 基础 | 活动名称\* | 必填 |
| 基础 | 开始\* / 结束时间\* | GMT+8；结束后未使用次数自动失效 |
| 基础 | 领取方式 | 手动领取 / 自动发放 |
| 基础 | 是否需要 KYC | 沿用现网 |
| 奖励 | 奖池总预算 | 留空 = 不限 |
| 奖励 | 转数设置、转盘设置 | 见 2.3、2.4 |
| 名单 | 白名单名单 | 见 2.5 |
| 流水 | 流水倍数 / 是否含奖金 / 计入流水的游戏 | 见 2.6 |
| 文案 | 奖励弹窗文案 | 支持 {bonus} |
| 文案 | 每日弹窗标题 | 只配标题，支持 {count}；留空用默认文案 |

与现网相比去掉：是否需要充值记录、人群范围、充值渠道、首次 / 非首次档位、白名单奖励档位、流水“含本金”。

### 2.3 转数设置

- 每人一轮 N 转（至少 1 转，最多 10 转），全部免费，可新增 / 删除。
- 每一转下拉选择使用哪个转盘（免费转盘1 / 2 / …），行底色 = 转盘色。
- 第 1 转进入白名单即可转，之后每转在上一转完成后解锁。
- 页面实时显示单人最高成本、期望成本。默认 3 转：第 1、2 转用转盘1，第 3 转用转盘2。

### 2.4 转盘设置（多转盘）

- 每个转盘是独立的 10 格奖励金额 + 整数概率（合计 100%，0 = 只展示不命中），顺时针从顶部起，第 1 格为大奖格。
- 卡片并排，每个转盘一种底色（蓝 / 橙 / 绿 / 紫 / 粉），名称可改，显示「第 x 转使用」；底部显示合计、期望、最高。
- 最多 5 个，新转盘复制上一个的配置；被引用或只剩 1 个时不可删除。

| 默认转盘 | 10 格金额（₱） | 概率（%） | 期望 | 最高 |
|---|---|---|---|---|
| 免费转盘1 | 7,890 / 789 / 78.9 / 2.34 / 1.23 / 4.56 / 12.3 / 23.4 / 45.6 / 7.89 | 0/0/0/30/35/20/5/0/0/10 | ₱3.45 | ₱12.3 |
| 免费转盘2 | 7,890 / 888 / 188 / 88 / 58 / 38 / 28 / 18 / 12.3 / 8.8 | 0/1/4/10/15/20/20/15/10/5 | ₱51.47 | ₱888 |

### 2.5 白名单名单（创建 / 编辑页内）

沿用现有导入逻辑（老用户充值转盘 / 登录送彩金白名单同款），不再单设页签。

- 须先保存活动，未保存点击导入提示「请先保存活动后再导入白名单」；保存成功弹窗提供「去导入白名单」。
- CSV 首行 phone，每行 1 个 09 开头 11 位手机号；提供模板下载、已导入文件下载（phone + 状态）。
- 名单状态：共 N 个手机号（未注册 x · 已注册生效 y）· 最近更新时间 · 操作人。
- 导入结果：总行数 / 有效 / 无效 / 文件内重复 / 插入 / 已存在 + BatchId。
- 名单内每人获得 1 轮转数；未注册手机号注册后自动生效；重复导入不重复发放；多次导入为追加。

### 2.6 流水要求

| 字段 | 说明 |
|---|---|
| 彩金提现所需流水倍数 | 默认 1 倍；稽核流水 = 中奖金额 × 倍数 |
| 稽核流水是否包含奖金 | 是 / 否 |
| 计入流水的游戏 | 全部游戏 / 指定游戏类别 / 指定游戏 |
| 指定游戏类别 | 6 类多选：Slots、Casino、Poker、Bingo、Arcade、Fishing；类别下新上架游戏自动计入 |
| 指定游戏 | 「选择游戏」弹窗（复用返水活动）：类别 → 厂商 → 游戏 ID 三级勾选，上级联动下级；可按名称 / ID 搜索、只看已选；保存提交游戏 ID |

保存校验：每个转盘 10 格金额 > 0、概率合计 = 100%、名称非空、至少被 1 转使用；指定类别至少 1 类；指定游戏至少 1 款。保存前二次确认（每转用的转盘、单人最高 / 期望成本、流水范围）；修改后未抽次数按新配置抽，写操作日志。

## 3. 预算告警与权限

### 3.1 预算告警与自动关闭

| 项 | 规则 |
|---|---|
| 顶部预算告警 | 接入现有「预算告警」（/api/admin/msg/get 的 budgetAlertNum + /api/admin/msg/budgetAlert/list）。消耗 ≥ 全局阈值（现网 budgetAlertPercent = 70%）进入列表；i18n global.budgetAlertActivityType 新增 whitelistSpin = 「白名单转盘活动」，显示活动名和消耗率，可单条 / 全部关闭 |
| 活动页内预警 | 白名单转盘「活动配置」列表上方显示「预算预警」条：列出本菜单下消耗 ≥ 70% 的活动（活动名 + 消耗率 + 剩余金额）和预算不足已自动关闭的活动，右侧「查看顶部告警」展开顶部告警条；没有时不显示。「已使用预算」列加消耗进度条和百分比：< 70% 绿色，≥ 70% 橙色并标「预算预警」，自动关闭红色；不限预算不显示进度。预警条不受顶部告警「关闭」影响，消耗回落或补充预算后自动消失 |
| 预算不足自动关闭 | 剩余预算 < 最小奖励（所有被使用转盘中概率 > 0 的最小金额，默认 ₱1.23）时自动关闭：状态变关闭、前台入口隐藏、未用次数不可抽；写操作日志；列表标记「预算不足自动关闭」。补充预算后可手动重新开启 |
| 不限预算 | 奖池总预算为空时不告警、不自动关闭 |

## 4. 活动统计

- 筛选：活动、会员账号、User ID、转盘、领取时间；支持导出 CSV，≥ 1 万条走异步。
- 汇总：白名单人数、发放次数、已抽次数和使用率、领取总额、预算使用、未使用次数的最高成本。
- 按转盘统计：每个转盘的已抽次数、各格实际命中分布、领取总额、人均。
- 领取明细：现网字段（ID / 会员ID / 会员账号 / 活动类型 / 领取金额 / 日期 / 领取时间）+ 新增「第几转」「转盘」「导入批次」。

### 4.1 操作日志

白名单转盘菜单下新增第三个页签「操作日志」（活动配置 | 活动统计 | 操作日志），记录本菜单的所有后台操作和系统自动操作；只读，不可编辑或删除。

| 项 | 规则 |
|---|---|
| 筛选 | 活动（含已删除活动）、操作类型、操作人（账号 / 系统）、操作时间（GMT+8）；搜索 / 重置 |
| 列 | 操作时间、操作人、操作类型、活动（编号 + 名称）、变更内容、IP |
| 变更内容 | 按字段列出「旧值 → 新值」，一次保存改了多个字段就列多行；转盘写明「转盘名 · 第 N 格金额 / 概率」，游戏写「游戏名（游戏 ID）」 |
| 操作类型 | 人工：新增活动、修改活动、开启活动、关闭活动、删除活动、白名单导入（文件名 + 导入结果 + BatchId）、下载名单、导出统计；系统：预算预警（消耗首次 ≥ 70%）、预算不足自动关闭、活动结束。系统操作的操作人记为「系统」，IP 为「-」 |
| 展示 | 时间倒序，每页 10 条；操作类型用不同颜色标签 |
| 保留 | 365 天 |
| 权限 | 新增按钮权限码 10141909 操作日志-查看；没有时不显示该页签 |
| 接口 | `GET /api/admin/activity/whitelistSpin/log/list`（activityId、opType、operator、startTime、endTime、pageNum、pageSize）；写入在服务端完成，写入失败不影响业务操作但需告警 |

原型 04 画板可筛选、翻页。

## 5. 前台 H5 与接口

1. 入口：首页独立挂件（显示 ×N），仅有资格的用户可见，见 5.2。
2. 每日活动弹窗：有资格的用户每天第一次登录进首页弹 1 次（替代原获得次数提示），见 5.1。
3. 转盘页：紫金主题 10 格，标题 LUCKY SPIN，副标题 Mega Jackpot up to {当前转盘最大金额}；盘面显示当前这一转所用转盘的 10 格金额；左上角返回图标回首页；底座顶部显示 Remaining spins。
4. 中奖轮播（底座）：本活动最近 30 条真实中奖，账号脱敏为前 3 + *** + 后 4 位；一次 2 条、每 2.2 秒上滚 1 条、无缝循环；≥ ₱789 高亮；每 60 秒刷新，自己抽中立即插到最前；≤ 2 条不滚动，0 条显示 Be the first to win!
5. 抽奖：点 GO 调 draw，前端转到返回的 slotIndex 停下。
6. 中奖弹窗：标题 LUCKY SPIN REWARDS；关闭后入账；有剩余显示 Spin Again (n)，没有显示 Play Now。
7. 异常：活动关闭、已结束或预算用完时提示 This event has ended。
8. 按钮：主按钮绿色渐变胶囊；次要按钮亮面绿色 8px 圆角。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/activity/whitelistSpin/info | spins[]（每转 wheelId + 10 格金额，不返回概率）、remaining、nextSpinNo、expireTime、jackpot、showGrantPopup、winners[] |
| POST | /api/activity/whitelistSpin/draw | 入参 requestId（幂等）；返回 slotIndex、amount、remaining、drawId |
| GET | /api/activity/whitelistSpin/winners | 最近 30 条中奖，服务端脱敏，不返回 userId |

draw 处理顺序：

1. 校验活动开启且在有效期、预算充足、用户有剩余次数，否则返回活动已结束。
2. 加锁，取该用户的下一转，先扣次数。
3. 按这一转 wheelId 对应转盘的概率抽格。
4. 写抽奖明细和稽核（稽核金额 = amount × 倍数，仅统计 wagerScope 内游戏的有效投注）。
5. 判断剩余预算 < 最小奖励则自动关闭活动，然后返回结果。

configJson：wheels[{wheelId, name, amounts[10], probabilities[10]}]、spins[{no, wheelId}]、withdrawWaterMult、needBonus、wagerScope{type: ALL / CATEGORIES / GAMES, categories, gameIds}、rewardPopupText、grantPopupText。服务端校验：wheels 1–5 个，spins 1–10 个且 wheelId 存在，每个转盘至少被 1 转使用。

### 5.1 每日活动弹窗

有资格的用户每天（GMT+8）第一次登录进入首页时弹出 1 次白名单转盘活动弹窗；替代原「获得次数提示」，同一天只弹一个。

| 项 | 规则 |
|---|---|
| 资格 | 已登录；活动开启且在有效期内；用户在白名单内且剩余次数 > 0；预算未用完。任一不满足不弹 |
| 触发 | 每天第一次登录成功后进入首页（含 App 冷启动自动登录）。当天弹过即不再弹，换设备也不再弹；00:00 后重新计算 |
| 计次 | 以曝光计次，由服务端按 userId + 日期记录；被更高优先级弹窗挡住、未实际展示的不计 |
| 队列位置 | 加入前端统一弹窗队列 `fullModalList`，key `whitelist-spin`，排在 `olduser-turntable` 之后、`golden-egg` 之前；21+ / 协议弹窗优先。同步更新 `docs/modal-queue-system.html` |
| 内容 | 只留 3 行，次数和 Spin Now 各出现一次：转盘头图 + 标题（含次数）+ 副标题（最高奖）+ 主按钮 Spin Now + 右上 ×；不显示到期时间。只有一版标题，不区分获得 / 提醒 |
| 文案 | 后台只配标题，支持 {count}。默认 "{count} Free Spins!"。副标题固定 "Win up to ₱{max}"（{max} = 当前转盘 10 格里的最大金额，即大奖格，与转盘页 Mega Jackpot 一致，默认 ₱7,890），按钮固定 "Spin Now" |
| 交互 | Spin Now 进入转盘页；× 关闭并缩向独立挂件；点遮罩不关 |
| 埋点 | `spin_entry_view`（entry = popup）、`popup_click`、`popup_close` |

接口：info 返回 `dailyPopup`（true = 今天该弹）；前端展示后调 `POST /api/activity/whitelistSpin/popupShown` 记曝光。

### 5.2 独立挂件（切图与需求在 GAM-444，原型 06）

白名单转盘做成单独的首页挂件，不并入现有挂件组（Invite / DEPOSIT Lucky Spin / 日历礼盒）。样式按 Figma 设计稿首页的 Lucky Spin 挂件（转盘 + 字标）；交互见原型 06 画板（可拖动吸边、点击进转盘、× 当天隐藏）。

| 项 | 规则 |
|---|---|
| 显示条件 | 与每日弹窗资格相同；由「活动展示开关」控制 |
| 位置 | 首页右侧，默认在现有挂件组上方，两者不重叠；只在首页显示 |
| 样式 | 转盘图标 + 右上角标 ×N（剩余次数），轻微旋转 / 呼吸动效；图标由美术提供（GAM-444） |
| 交互 | 点击进入转盘页；可拖动，松手吸附屏幕左右边缘；位置本地记住 |
| 关闭 | 右上小 × 可隐藏，当天不再显示；次日或有新导入批次时重新显示 |
| 消失 | 次数用完、活动关闭 / 结束 / 预算不足自动关闭时立即隐藏（从转盘页返回首页时刷新 info） |
| 埋点 | `widget_click`（item = whitelist_spin / hide）、`spin_entry_view`（entry = widget） |

### 5.3 音乐与音效

转盘页自带背景音乐和 6 个音效，素材前端固定（不进后台配置），由美术 / 音频提供（GAM-444）。原型 08 画板可试听（合成音示意）。

| 声音 | 触发 | 说明 |
|---|---|---|
| 背景音乐 | 进入转盘页自动播放，循环 | 离开转盘页停止；App 切后台暂停、回前台继续；转动和中奖时音量压低，结束后恢复 |
| GO | 点 GO 开始转动 | 短促启动音 |
| 转动嘀嗒 | 指针每经过一格响一次 | 随转速变慢自然变疏 |
| 停下 | 转盘停在命中格 | 低音“咚” |
| 中奖 | 中奖弹窗出现 | 金额 < ₱789 用普通中奖音；≥ ₱789 用大奖音（更长、带金币声） |
| 按钮 | Spin Again / Play Now / 弹窗按钮 | 轻点击音 |

- 自动播放：默认开启。浏览器和 WebView 禁止无交互自动播声音时，用户在页面上第一次点击后开始播放；App WebView 允许无手势播放时进入即播。
- 静音开关：转盘页右上角喇叭图标，一键关闭音乐和音效；状态存在本地（H5 localStorage / App 本地存储），下次进入沿用；弹窗打开时也能点。
- 音量：背景音乐约 40%，音效 100%；iOS 静音拨片打开时不出声。
- 加载：进入转盘页预加载；加载失败只是没声音，不影响抽奖。
- 素材规格：MP3 / AAC；背景音乐 30–60 秒无缝循环、≤ 300KB；音效各 ≤ 50KB、开头无静音空白。

## 6. 验收要点

- 第 N 转只按该转指定转盘的概率出结果；抽 100 次分布接近配置，概率为 0 的格子（含大奖 ₱7,890）不会命中。
- 改了某转使用的转盘后，未抽次数按新转盘抽；前台盘面金额 = 该转转盘的 10 格金额。
- 转盘被引用或只剩 1 个时不可删除。
- 预算消耗到 70% 时顶部「预算告警」+1 并出现「白名单转盘活动」，同时活动列表上方出现「预算预警」条、该行进度条变橙并标「预算预警」；剩余预算 < 最小奖励时自动关闭。
- 无对应权限码的账号看不到菜单 / 按钮，接口返回无权限。
- 指定类别 / 指定游戏之外的投注不计入该彩金流水；类别下新上架游戏自动计入。
- 抽奖中被打断（生物识别弹窗、断网）次数已扣、结果可查；重复点击不重复扣次数。
- 未保存活动不能导入；重复手机号计入“已存在”，不重复发放。
- 开启中或有未使用次数的活动不可删除；删除后记录仍可查。
- 轮播只显示本活动真实中奖且已脱敏。
- 时间一律 GMT+8，覆盖 00:00 前后跨天。
- 每日弹窗：有资格用户当天第一次登录弹 1 次，当天再登录、换设备都不弹；跨 00:00 后再登录会弹；与老用户转盘、砸金蛋同时触发时按队列串行弹。
- 剩余次数为 0、活动关闭或预算用完时，弹窗和挂件都不出现；弹窗只有一版标题「{count} Free Spins!」，不区分获得 / 提醒。
- 挂件点击进转盘页；拖动后吸边；点 × 当天隐藏、次日恢复；与现有挂件组不重叠。
- 音乐音效：进入转盘页播放背景音乐（首次点击后开始亦可）；GO、每过一格嘀嗒、停下、中奖音效触发正确，≥ ₱789 播大奖音；点喇叭静音后全部无声，重进仍为静音；离开转盘页音乐停止。
